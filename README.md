# retail-sales-analysis
Retail sales analysis project using Microsoft Excel.

## Overview
The objective of this project is to analyze transactional data from a simulated dataset utilizing Microsoft Excel in order to evaluate overall retail sales performance.

## Project Objective
The analysis aims to:
- Evaluate overall sales performance.
- Compare sales performance across products.
- Compare sales performance across categories.
- Identify products with the highest and lowest sales performance.

## Dataset
The dataset used in this project is a simulated retail sales dataset created for learning purposes. It contains 12 transactions with information about products, categories, quantities, unit prices, discounts, and total sales.

## Analysis

The analysis covers:
- Overall sales performance
- Product performance
- Category performance
- Sales quantity
- Average sales
- Transaction count

## Key Findings

- Products with the highest unit sales do not necessarily generate the greatest revenue.
- Monitors generate the highest revenue despite recording the lowest unit sales.
- Conversely, mice represent the highest-selling product by unit volume, yet yield the lowest revenue.

## Tools

- Microsoft Excel
- Excel Tables
- Excel formulas

## Limitations
This project uses a small simulated dataset and is intended for learning purposes. Therefore, the findings should not be considered representative of actual retail business performance.
